## Organicémonos
- Hola, bienvenido de nuevo.
- ​Tanto si está organizando sus datos personales para ​su propio uso como si está organizando los datos de un proyecto para el trabajo, ​hay ciertos Procedimientos que debe seguir para ​asegurarse de que sus datos son fáciles de encontrar y utilizar.
- ​En este vídeo, trataremos ​algunas de las mejores prácticas de organización ​y también echaremos un vistazo a algunas formas diferentes en que ​pueden organizarse los datos de un proyecto.
- ​Existen muchas de las mejores prácticas que ​puede utilizar a la hora de organizar los datos, ​incluidas las convenciones de nomenclatura, el plegado, ​y el archivo de archivos antiguos.
- ​Hemos hablado antes de la nomenclatura de archivos, ​que también se conoce como convenciones de nomenclatura.
- ​Se trata de directrices coherentes ​que describen el contenido, ​la fecha o la versión de un archivo en su nombre.
- ​Básicamente, esto significa que debe utilizar nombres ​lógicos y descriptivos para ​sus archivos para que sean más fáciles de encontrar y utilizar.

- ​Hablando de encontrar cosas fácilmente, ​organizar sus archivos en carpetas ayuda a ​mantener los archivos relacionados con el proyecto juntos en un mismo lugar.
- ​Esto se denomina agrupar.
- ​Por ejemplo, todos los archivos relacionados con su plan de vacaciones ​pueden ir en la carpeta Vacaciones2025.
- ​A continuación, puede dividir aún más esa carpeta ​creando subcarpetas como itinerario o fotos, ​dependiendo de a qué otras cosas le gustaría acceder fácilmente.
- ​También puede ser útil trasladar los proyectos antiguos a ​un lugar separado para crear ​un archivo y reducir el desorden.
- ​Es mucho más fácil encontrar y utilizar ​mis archivos cuando les pongo un nombre ​que tenga sentido y permita realizar búsquedas ​y cuando los organizo en carpetas.
- ​Hace que todos mis datos sean más accesibles y útiles.

- ​Además de estas tres mejores prácticas, ​hay dos cosas más que querrá tener en cuenta ​a la hora de organizar los datos para su uso laboral.
- ​En primer lugar, los datos del proyecto que utilizará para ​trabajar podrían ser consultados y utilizados por varias personas.
- ​Es importante alinear ​sus prácticas de nomenclatura y almacenamiento con ​su equipo para evitar cualquier confusión.
- ​Su equipo también podría desarrollar ​prácticas de metadatos como crear ​un archivo que describa las convenciones de nomenclatura del proyecto ​para facilitar su consulta.
- ​Más adelante hablaremos con más detalle de las convenciones de nomenclatura ​para los archivos de trabajo.
- ​En segundo lugar, debe pensar en la frecuencia con la que ​realiza copias de los datos y los almacena en distintos lugares.
- ​Más importante aún, porque si los datos se almacenan ​en muchas bases de datos u hojas de cálculo diferentes, ​pueden contradecirse y dar lugar a errores más adelante.

- ​También almacenar datos en ​múltiples lugares ocupa mucho espacio.
- ​Las bases de datos relacionales pueden ayudarle a evitar ​la duplicación de datos y a almacenar sus datos de forma más eficiente.
- ​Puede utilizar estas prácticas para organizar ​los datos de distintas formas según su proyecto.
- ​Veamos algunos ejemplos de organización de datos.
- ​Aquí tengo algunas carpetas de proyectos de muestra, ​cada una organizada de una forma ligeramente distinta.
- ​Vamos a abrirlas y ver qué aspecto tienen.
- ​Empezaremos con la carpeta de alto nivel Finanzas.

- ​La carpeta Finanzas se ha organizado por categorías.
- ​Hay subcarpetas como Presupuesto, ​Facturas y Nóminas ​que representan diferentes categorías.
- ​Hagamos clic en "Facturas" para ver lo que hay allí.
- ​En la carpeta de facturas, ​podemos ver que tenemos otro conjunto ​de subcarpetas etiquetadas ​por año, 2014, 2015.
- ​Parece que están en orden cronológico.
- ​A veces, la forma en que están organizados los archivos puede decirnos ​cómo están organizados también los datos dentro de esos archivos.
- ​Abramos un archivo para ver si es correcto.

- ​En la subcarpeta 2014, ​hay un archivo con facturas de junio.
- ​Si lo abrimos, podemos ​ver que se han organizado por fecha, ​al igual que las carpetas.
- ​Hay distintas formas de organizar ​los datos dependiendo de para qué los necesitemos.
- ​La organización por categorías de las subcarpetas y ​finanzas me facilitó ​ir directamente a las facturas, ​pero la organización cronológica ​de la subcarpeta de facturas ​puede ayudarnos a encontrar datos financieros ​desde la fecha exacta que buscamos.
- ​También hay otras formas de organizar los datos: ​por orden de importancia o incluso por ubicación.
- ​Por ejemplo, una empresa puede utilizar ​una organización jerárquica para que los datos de los empleados reflejen ​la estructura de su organización de empleados.
- O una empresa ​que trabaje con datos geográficos ​podría optar por organizarlos por ubicación.

- ​Es una buena idea tomarse tiempo ​al principio de un proyecto para considerar cuáles ​serán los mejores métodos de organización a los que usted y su equipo ​podrán ceñirse.
- ​Aquí tiene otra forma de pensar al respecto.
- ​Los datos desorganizados son como una habitación desordenada.
- ​Son abrumadores, cuesta encontrar algo ​en ellos y empeoran cuanto más tiempo evite limpiarlos.
- ​Pero si se asegura desde el principio ​de que sabe dónde colocar sus archivos, ​podrá mantener sus datos de trabajo organizados, ​fáciles de usar y sin errores.
- ​Ahora que ya ve lo importante que es mantener ​los datos organizados tanto para uso personal como laboral, ​examinaremos más de cerca las ​convenciones de denominación de archivos y cómo se trasladan a sus bases de datos.

## Pautas para la organización de archivos
- El objetivo de todo Analista de datos es realizar análisis de datos eficientes.
- Una forma de aumentar la eficiencia de sus análisis es racionalizar los procesos que ayudan a ahorrar tiempo y energía a largo plazo.
- Unos nombres de archivo significativos, lógicos y coherentes ayudan a los analistas de datos a organizar sus datos y automatizar su proceso de análisis.
- Cuando utiliza pautas coherentes para describir el contenido, la fecha o la versión de un archivo y su nombre, está utilizando convenciones de nomenclatura de archivos.
- En esta lectura, aprenderá más sobre las mejores prácticas para las convenciones de nomenclatura de archivos y la organización de archivos.

- Mejores prácticas para nombrar archivos
   - Las convenciones de nomenclatura de archivos le ayudan a organizar, acceder, procesar y analizar los datos porque actúan como puntos de referencia rápidos para identificar lo que hay en un archivo.
   - Una práctica importante es decidir las convenciones de denominación de archivos -como equipo o empresa- al principio de un proyecto.
   - Esto le evitará perder tiempo actualizando los nombres de los archivos más adelante, lo que puede ser un proceso que lleve mucho tiempo.
   - Además, debería alinear los nombres de los archivos de su proyecto con las convenciones de denominación de archivos existentes en su equipo o empresa.
   - No querrá perder tiempo aprendiendo una nueva convención de denominación de archivos cada vez que busque un archivo en un proyecto nuevo 
   - También es fundamental asegurarse de que los nombres de los archivos sean significativos, coherentes y fáciles de leer.
   - Los nombres de los archivos deben incluir
      - El nombre del proyecto
      - La fecha de creación del archivo
      - La versión de revisión
      - Un estilo y un orden coherentes
   - Además, las convenciones de nomenclatura de archivos deben actuar como puntos de referencia rápidos para identificar lo que contiene el archivo.
   - Por ello, deben ser breves y directos. 
   - En las siguientes secciones, explorará cada parte del nombre de un archivo de Informe de ventas que sigue una convención de nomenclatura establecida, SalesReport_20231125_v02.
   - Este ejemplo le ayudará a comprender las partes clave de un nombre de archivo sólido y por qué son importantes. 

   - Nombre
      - Dar a un archivo un nombre significativo para describir su contenido facilita su búsqueda.
      - También facilita la comprensión del tipo de datos que contiene el archivo.
      - En el ejemplo, el nombre del archivo incluye el texto SalesReport, una descripción sucinta de lo que contiene el archivo: un informe de ventas. 

   - Fecha de creación
      - Saber cuándo se creó un archivo puede ayudarle a comprender si es relevante para su análisis actual.
      - Por ejemplo, es posible que sólo desee analizar datos de 2023. 
      - En el ejemplo, el año se describe como 20231125.
      - Esto se lee como el informe de ventas del 25 de noviembre de 2023 siguiendo el formato de año, mes y día (AAAAMMDD) del estándar internacional de fechas.
      - Tenga en cuenta que cada país sigue una convención de fechas diferente, así que asegúrese de conocer el estándar de fechas que sigue su empresa

   - Versión de revisión
      - Incluir una versión de revisión le ayuda a asegurarse de que está trabajando con el archivo correcto.
      - No querrá hacer ediciones en una versión antigua de un archivo sin darse cuenta Cuando incluya números de revisión en el nombre de un archivo, lidere con un cero.
      - De esta forma, si su Equipo alcanza más de nueve rondas de revisiones, los dobles dígitos ya están incorporados a su convención. 
      - En el ejemplo, la versión se describe como v02.
      - La v es la abreviatura de la versión del archivo, y el número que sigue a la v indica en qué ronda de revisiones se encuentra actualmente el archivo. 

   - Coherencia en el orden y el estilo
      - Asegúrese de que la información que incluye en el nombre de un archivo sigue un orden coherente.
      - Por ejemplo, no querrá que la versión tres del Informe de ventas del ejemplo se titule 20231125_v03_InformeVentas.
      - Sería difícil encontrar y comparar varios documentos.
      - Cuando utiliza espacios y caracteres especiales en el nombre de un archivo, es posible que el software no pueda reconocerlos, lo que causa problemas y errores en algunas aplicaciones.
      - Una alternativa es utilizar guiones, guiones bajos y mayúsculas.
      - El ejemplo incluye guiones bajos entre cada dato, pero su Equipo podría optar por utilizar también guiones entre el año, el mes y la fecha: SalesReport_2023_11_25_v02.

   - Garantice la coherencia del equipo
      - Para asegurarse de que todos los miembros del equipo utilizan las convenciones de nomenclatura de archivos acordadas, cree un archivo de texto como muestra que incluya todas las convenciones de nomenclatura de un proyecto.
      - Esto puede beneficiar a los nuevos miembros del equipo para ayudarles a ponerse al día rápidamente o a un miembro actual del equipo que sólo necesite un repaso de las convenciones de nomenclatura de archivos.

   - Organización de archivos
      - Para mantener sus archivos organizados, cree carpetas y subcarpetas en una jerarquía lógica para asegurarse de que los archivos relacionados se almacenan juntos y se pueden encontrar fácilmente más tarde.
      - Una jerarquía es una forma de organizar archivos y carpetas.
      - Las carpetas de temas más amplios se sitúan en la parte superior de la jerarquía, y las subcarpetas y archivos más específicos están contenidos dentro de esas carpetas.
      - Cada carpeta puede contener otras carpetas y archivos.
      - Esto le permite agrupar archivos relacionados y facilita la búsqueda de los archivos que necesita.
      - Además, es una buena práctica almacenar los archivos finalizados por separado de los archivos en curso para que los archivos que necesita sean fáciles de encontrar.
      - Archive los archivos antiguos en una carpeta separada o en un lugar de almacenamiento externo.

- Puntos clave
   - Utilice convenciones de denominación de archivos coherentes y significativas en todo el proyecto para ahorrar tiempo a usted y a su equipo, facilitando la búsqueda y el uso de los datos.
   - Las convenciones de denominación de archivos deben ser acordadas por todos los Miembros del equipo antes de comenzar un proyecto y deben describir el proyecto incluyendo su nombre, la fecha y la versión de revisión.
   - Documente esta información en un lugar al que los Miembros del equipo puedan acceder.

## Métodos eficaces de denominación y organización de archivos
- Review your knowledge of effective file naming and file organization practices.

- Is this a good file name?
   - Categorize each file name by dragging it to the appropriate area. Or use the plus sign to choose where it belongs.

- Best practice
   - `2021-SPRING-inventory-LP-v2`
   - `Cafe_Restock_Data_2021_05_24`
   - `Q4-21-Data-Report-v4`
- Needs improvement
   - `Q421data-final-FINAL-LP-JD-AP-AP2`
   - `New text 4-dave`
   - `Q21DataReport0106`

- Is this a good file organization practice?
   - Categorize each file organization practice by dragging it to the appropriate area. Or use the plus sign to choose where it belongs.

- Best practice
   - Most files can fit in your hierarchy if you’ve done a good job of mapping it out.
   - Create folders and subfolders hierarchically so that related files are stored together.
   - Keep ongoing work separate from completed work.
   - Back up files often to avoid losing work.
- Needs improvement
   - Keep all current and completed work in one primary folder.
   - Avoid resaving your files as this can be unnecessary. Saving your files once is enough.
   - Save files locally on your desktop so you can find them easily.
   - Keep your files in only one place.
   - Create a new folder every time you add a file to the project.
