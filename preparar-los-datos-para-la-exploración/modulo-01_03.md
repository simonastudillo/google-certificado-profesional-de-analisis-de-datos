# Diferenciar formatos y estructuras de datos

## Descubra los formatos de datos
- Yo no sé ustedes, pero cuando ​estoy eligiendo una película para ver, ​A veces me quedo atascado entre un par de opciones.
- ​Si tengo ganas de emoción o suspense, ​Podría ir por un thriller, ​pero si necesito una buena carcajada, ​Elijo una comedia.
- ​Si realmente no puedo decidirme entre dos películas, ​Puede que incluso utilice mis conocimientos de Análisis de datos ​para compararlas y contrastarlas.
- ​Ahora que lo pienso, realmente tiene que haber ​más películas sobre analistas de datos.
- ​Lo vería, pero como ​no podemos ver una película sobre Datos, ​al menos no todavía, haremos ​lo siguiente mejor: ¡ver datos sobre películas! ​Vamos a ver ​esta hoja de cálculo con Datos de películas.
- ​Sabemos que podemos comparar diferentes películas y géneros cinematográficos.

- ​Resulta que se puede hacer lo mismo con ​datos y formatos de datos.
- ​Utilicemos nuestra hoja de cálculo con datos de películas ​para entender cómo funciona.
- ​Empezaremos con datos cuantitativos y cualitativos.
- ​Si echamos un vistazo a la columna A, encontraremos los títulos de las películas.
- ​Se trata de Datos cualitativos porque no se pueden contar, ​no se pueden medir ni expresar fácilmente con números.
- ​Los Datos cualitativos suelen enumerarse como ​un nombre, una categoría o una descripción.
- ​En nuestra Hoja de cálculo, los títulos de las películas y los miembros del reparto son datos cualitativos ​cAST son Datos cualitativos.

- ​A continuación están los Datos cuantitativos, ​que se pueden medir o ​contados y expresados como un número.
- ​Son datos con una cierta cantidad, cantidad o rango.
- ​En nuestra Hoja de cálculo ​las dos últimas columnas muestran el presupuesto ​presupuesto e Ingresos de taquilla.
- ​Los Datos de estas columnas están expresados en dólares, ​que se pueden contar, ​por lo que sabemos que los datos son cuantitativos.
- ​Podemos profundizar aún más en los Datos cuantitativos ​y desglosarlos en datos discretos o continuos.
- ​Veamos primero los Datos discretos.
- ​Son datos que se cuentan ​y tienen un número limitado de valores.

- ​Volviendo a nuestra Hoja de cálculo, ​encontraremos el Presupuesto de cada película y los ​de cada película en las columnas M ​y N.
- Ambos son ejemplos de ​datos discretos que pueden ser ​contados y tienen un número limitado de valores.
- ​Por ejemplo, la cantidad de dinero ​que gana una película sólo puede representarse ​con exactamente dos dígitos después ​el decimal para representar céntimos.
- ​No puede haber nada entre uno y dos céntimos.
- Datos discretos no se limitan a cantidades en dólares. Otros ejemplos de datos discretos son las estrellas y los puntos. Cuando no se permiten mediciones parciales (medias estrellas o cuartos de punto), los datos son discretos. Si no se acepta nada que no sean estrellas o puntos completos, los datos se consideran discretos.
- ​Datos continuos pueden medirse utilizando un temporizador, y ​su valor puede mostrarse como un decimal con varias posiciones.
- ​Imaginemos una película sobre analistas de datos ​que definitivamente voy a protagonizar algún día.
- ​Podrías expresar la duración de esa película como ​110.
- 356 minutos.

- ​Incluso podría añadir datos fraccionarios ​después del punto decimal si fuera necesario.
- ​También hay Datos nominales y ordinales.
- ​Datos nominales son un tipo de datos cualitativos ​datos cualitativos que se clasifican sin un orden establecido.
- ​En otras palabras, estos Datos no tienen una secuencia.
- ​He aquí un ejemplo rápido.
- ​Supongamos que está recopilando datos sobre películas.
- ​Se pregunta a la gente si ha visto una película determinada.

- ​Sus respuestas serían datos nominales.
- ​Podrían responder "Sí" ​"No" o "No estoy seguro" ​Estas opciones no tienen un orden concreto.
- ​Datos ordinales, por otro lado, ​son un tipo de datos cualitativos con un orden o escala establecidos.
- ​Si pidieras a un grupo de personas ​que clasifiquen una película del 1 al 5, ​algunos la clasificarían con un 2, ​otros un 4, y así sucesivamente.
- ​Estas Clasificaciones están ordenadas según ​la película.
- ​Hablemos ahora de Datos internos, ​datos que viven dentro de los propios sistemas de una empresa.
- ​Por ejemplo, si un estudio de cine hubiera compilado todos los ​los Datos de la hoja de cálculo utilizando ​sólo sus propios métodos de recopilación, ​entonces serían sus Datos internos.

- ​Lo mejor de los Datos internos es que suelen ser más fiables y fáciles de recopilar ​suelen ser más fiables y fáciles de recopilar, ​pero en esta hoja de cálculo, ​es más probable que el estudio de cine ​haya tenido que usar datos propios o compartidos ​por otros estudios y ​fuentes porque incluye películas que ellos no hicieron.
- ​Eso significa que estarían recopilando Datos externos.
- ​Datos externos son, lo has adivinado, ​datos que viven y ​se generan fuera de una organización.
- ​Datos externos se vuelven particularmente valiosos cuando ​su Análisis depende de tantas fuentes como sea posible.
- ​Lo bueno de estos datos es que están estructurados.
- ​Datos estructurados son datos ​que están organizados en un formato determinado, ​como filas y columnas.
- ​Las hojas de cálculo y las bases de datos relacionales son ​dos ejemplos de software ​que pueden almacenar datos de forma estructurada.

- ​Tal vez recuerdes nuestra anterior exploración ​del pensamiento estructurado, ​que te ayuda a añadir un framework a un problema para que ​resolverlo de forma organizada y lógica.
- ​Lo mismo ocurre con los datos estructurados.
- ​Having a framework for the Data makes the data ​que los datos sean más fáciles de buscar y estén más preparados para el Análisis.
- ​Como Analista de datos, ​trabajarás con muchos Datos estructurados, ​que suelen presentarse en forma de ​una tabla, una hoja de cálculo o una base de datos relacional, ​pero a veces te encontrarás con Datos no estructurados.
- ​Datos que no están organizados de ninguna manera fácilmente identificable ​manera fácilmente identificable.
- ​Los archivos de audio y vídeo son ejemplos de Datos no estructurados ​porque no hay una forma clara de ​identificar u organizar su contenido.
- ​Datos no estructurados pueden tener una estructura interna, ​pero los Datos no encajan ordenadamente en filas y ​columnas como los datos estructurados.
- Y ya está ​Esperamos que ahora esté más familiarizado con ​los formatos de Datos y cómo utilizarlos en tu trabajo.

## Formatos de datos en la práctica
- Cuando piensa en la palabra "formato", le pueden venir a la mente muchas cosas.
- Piense en un anuncio de su tienda favorita.
- Puede encontrarlo en forma de anuncio impreso, de valla publicitaria o incluso de anuncio publicitario.
- La Información se presenta en el formato que mejor le funciona para asimilarla.
- El formato de un Conjunto de datos se parece mucho a eso, y elegir el formato adecuado le ayudará a gestionar y utilizar sus datos de la mejor manera posible.
