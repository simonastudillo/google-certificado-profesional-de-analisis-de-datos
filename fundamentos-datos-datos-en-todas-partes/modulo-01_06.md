## Estrategias de evaluación
- A medida que avance en este Programa, completará evaluaciones puntuadas al final de cada Módulo.
- Las evaluaciones son una señal útil para que anote sus progresos o identifique los conceptos o habilidades que necesita repasar.
- Sin embargo, a veces las evaluaciones pueden resultar abrumadoras.
- Abordarlas con una estrategia puede hacerlas más manejables.
- Para ayudarle a conseguirlo, esta lectura le proporcionará una lista de consejos y estrategias que puede utilizar para prepararse para el éxito y sentirse seguro de su capacidad para superarlas.

## Desafío del módulo 1

1. ¿Cuál de las siguientes afirmaciones describe correctamente los datos y el Análisis de datos? Seleccione todas las que correspondan.
   - [ ] Análisis de datos es crear nuevas formas de entender lo desconocido utilizando datos brutos.
   - [x] El Análisis de datos implica recopilar, transformar y organizar los datos.
   - [x] Los Datos son una colección de hechos.
   - [x] Uno de los objetivos del Análisis de datos es extraer conclusiones.
> Buen trabajo

2. Rellene el espacio en blanco: Ciencia de datos es la creación de nuevas formas de modelado y _____ mediante el uso de datos en bruto.
   - [x] comprender lo desconocido
   - [ ] compartir estadísticas
   - [ ] organizar la información
   - [ ] responder a las preguntas existentes
> Buen trabajo

3. ¿Cuáles de las siguientes actividades son elementos de la toma de decisiones basada en datos? Seleccione todas las que correspondan.
   - [x] Solicitud de observaciones a expertos en la materia
   - [x] Encontrar datos relevantes
   - [ ] Excluya la información basada en la intuición humana
   - [x] Definir la necesidad del negocio (Negocio a negocio)
> Buen trabajo

4. Una empresa quiere aumentar sus ventas un 10% en los próximos 12 meses. El Equipo de datos ayuda a conseguir este objetivo recopilando datos sobre las ventas actuales, su mercado objetivo y sus competidores. Esto les ayuda a identificar la diferencia entre dónde están hoy y dónde quieren estar dentro de un año. ¿Qué describe este escenario?
   - [ ] Orientar las decisiones empresariales
   - [ ] Análisis del futuro
   - [x] Análisis de déficits
   - [ ] Planificación
> Buen trabajo

5. Rellene el espacio en blanco: Los analistas de datos utilizan un enfoque _____ para identificar, describir y resolver retos o problemas. 
   - [ ] generalizado
   - [x] orientado a los problemas
   - [ ] visión de conjunto
   - [ ] rentable
> Buen trabajo

6. ¿Cuáles de los siguientes son ejemplos de pensamiento analítico? Seleccione todos los que procedan.
   - [x] Considerar los mejores formatos gráficos para comunicar visualmente la información
   - [ ] Utilizar la intuición para tomar decisiones
   - [x] Identificar y definir un problema y, a continuación, resolverlo utilizando los datos de forma organizada
   - [x] El hecho de que dos datos evolucionen en la misma dirección no significa necesariamente que estén relacionados
> Buen trabajo

7. Un profesional de los Datos que trabaja en una organización sin ánimo de lucro se prepara para un proyecto sobre silvicultura comunitaria. Utilizan sus Destrezas analíticas para determinar lo que quieren conseguir con los Datos. También dan prioridad a mantenerse centrados y en el buen camino. ¿Qué aspecto del pensamiento analítico describe este escenario?
   - [x] Pensamiento estratégico
   - [ ] Visualización de datos
   - [ ] Pensamiento colaborativo
   - [ ] Pensamiento basado en la intuición
> Buen trabajo

8. ¿Cuál es la Causa raíz de un problema?

9. Un profesional de Datos siempre está interesado en aprender nuevas habilidades y adquirir Conocimientos. A menudo buscan tareas desafiantes en el trabajo y experiencias de desarrollo profesional. ¿Qué Destrezas analíticas describe este escenario?
   - [ ] Comprender el contexto

10. ¿Cuál de los siguientes ejemplos demuestra la toma de decisiones basada en datos? Seleccione todos los que corresponda.
