- ​Empecemos con las hojas de cálculo.
- ​Una vez más, hay muchas soluciones de hojas de cálculo diferentes, pero ​dos opciones populares son Microsoft Excel y Google Sheets.
- ​En pocas palabras, una hoja de cálculo es una hoja de trabajo digital.
- Almacena ​, organiza y clasifica los datos.
- ​Esto es importante porque la utilidad de los datos depende de qué tan bien estén ​estructurados.
- ​Cuando colocas tus datos en una hoja de cálculo, puedes ver patrones, ​agrupar información y encontrar fácilmente la información que necesitas.
- ​Las hojas de cálculo también tienen algunas características realmente útiles llamadas fórmulas y funciones.

- ​Una fórmula es un conjunto de instrucciones que realiza un ​cálculo específico con los datos de una hoja de cálculo.
- ​Las fórmulas pueden hacer cosas básicas como sumar, restar, multiplicar y ​dividir, pero no terminan ahí.
- ​También puede usar fórmulas para encontrar el promedio de un conjunto de números.
- ​Busque un valor en particular, ​devuelva la suma de un conjunto de valores que cumpla con una regla en particular y mucho más.
- ​Una función es un comando preestablecido que ejecuta automáticamente un ​proceso o una tarea específicos con los datos de una hoja de cálculo.
- ​Suena bastante técnico, lo sé, así que vamos a desglosarlo.
- ​Piense en una función como una ​forma más simple y eficiente de hacer algo que normalmente llevaría mucho tiempo.

- ​En otras palabras, las funciones pueden ayudarlo a ser más eficiente.
- ​Estos son los aspectos básicos de las hojas de cálculo por ahora.
- ​Más adelante, los verás en acción y empezarás a trabajar tú mismo con hojas de cálculo.
- ​La siguiente herramienta de análisis de datos se llama lenguaje de consulta.
- ​Un lenguaje de consulta es un lenguaje de programación de computadora que permite recuperar y ​manipular datos de una base de datos.
- ​Aprenderás algo llamado lenguaje de consulta estructurado, ​más comúnmente conocido como SQL.
- ​SQL es un lenguaje que permite a los analistas de datos comunicarse con una base de datos.

- ​Una base de datos es una colección de datos almacenados en un sistema de computadora.
- ​SQL es el lenguaje de consulta estructurado más utilizado por un par de razones.
- ​Es fácil de entender y funciona muy bien con todo tipo de bases de datos.
- ​Con SQL, los analistas de datos pueden acceder a los datos que necesitan realizando una consulta.
- ​Aunque consulta significa pregunta, me gusta pensar que es más bien una solicitud.
- ​Así que estás solicitando que la base de datos haga algo por ti.
- ​Puedes pedirle que haga muchas cosas diferentes, como insertar, eliminar, ​seleccionar o actualizar datos.

- ​Vale, esa es una visión de alto nivel de SQL.
- ​En un vídeo posterior, lo exploraremos más a fondo y ​utilizaremos SQL para hacer cosas realmente interesantes con los datos.
- ​Por último, hablemos de la visualización de datos.
- ​Ha aprendido que la visualización de datos es la representación gráfica de la ​información.
- ​Algunos ejemplos incluyen gráficos, mapas y tablas.
- ​La mayoría de las personas procesan las imágenes con más facilidad que las palabras por sí solas.
- ​Por eso las visualizaciones son tan importantes.

- ​Ayudan a los analistas de datos a comunicar sus conocimientos a los demás de una ​manera eficaz y convincente.
- ​Cuando piensa en el proceso de análisis de datos, después de preparar, ​procesar y analizar los datos, ​los conocimientos se visualizan para que puedan entenderse y compartirse.
- ​Esto facilita que la parte interesada saque conclusiones ​, tome decisiones y elabore estrategias.
- ​Algunas herramientas de visualización populares son Tableau y Looker.
- A ​los analistas de datos les gusta usar Tableau porque les ayuda a crear imágenes que son muy ​fáciles de entender.
- ​Esto significa que incluso los usuarios sin conocimientos técnicos pueden obtener la información que necesitan.
- ​Looker también es popular entre los analistas de datos porque les brinda ​una manera fácil de crear imágenes basadas en los resultados de una consulta.

- ​Con Looker, puede ofrecer a la parte interesada una imagen completa de su trabajo ​mostrándoles los datos de visualización y los datos reales relacionados con él.
- ​Todas las herramientas de visualización tienen excelentes funciones que son útiles en diferentes ​situaciones.
