   - [ ] datos insuficientes
   - [ ] causalidad
   - [x] azar

1. Rellene el espacio en blanco: Si un profesional de los datos calcula una potencia estadística de al menos el 80%, es probable que los resultados de su experimento se deban a una _____ entre los grupos comparados, y no al azar.
   - [ ] ligera similitud
   - [x] diferencia real
   - [ ] anomalía confirmada
   - [ ] conexión prevista
> Buen trabajo

2. Una empresa tiene 1.000 tiendas en todo el país. Cada tienda hace un seguimiento de su inventario en tiempo real utilizando su sistema de punto de venta. Cada noche, los datos de inventario de cada tienda se envían a una base de datos central. Cuando los clientes visitan el sitio web de la empresa, pueden comprobar si su tienda local tiene un artículo concreto en stock, lo que el sitio web hace consultando la base de datos central. Lamentablemente, los clientes acuden a las tiendas y se encuentran con que el artículo que desean está agotado, a pesar de que el sitio web decía que estaba disponible. ¿Qué problema de integridad de datos describe este escenario?
   - [x] Replicación 
   - [ ] Recopilación
   - [ ] Transferencia
   - [ ] Manipulación
> Buen trabajo

2. Una agencia gubernamental opera un conjunto de sensores meteorológicos. Los sensores utilizan la resistencia eléctrica de un trozo de platino (Pt) para detectar la temperatura. Los datos brutos de estos sensores se expresan en ohmios de Pt. Estos datos se envían a una base de datos, donde se codifican en grados Celsius. Uno de los sensores se sustituyó por una unidad cuya salida de datos brutos está preconvertida a grados Celsius. Cuando la salida se envió a la base de datos, la fórmula de Pt ohmios a grados Celsius se aplicó por segunda vez, lo que causó confusión en torno a las lecturas de este sensor. ¿Qué problema de integridad de datos describe este escenario?
   - [ ] Vulnerabilidad de la seguridad
   - [ ] Replicación
   - [ ] Transferencia
   - [x] Manipulación
> Buen trabajo

3. En una Encuesta sobre una nueva aplicación para teléfonos inteligentes, el 65% de los encuestados afirma que recomendaría la aplicación a otras personas. El Margen de error de la Encuesta es del 3%. Basándose en ese margen de error, ¿qué Rango refleja la verdadera respuesta de la población?
   - [ ] 68-71%
   - [ ] 60-63%
   - [ ] 65-68%
   - [x] 62-68%

4. Un concesionario de coches realiza una encuesta para saber por qué los clientes eligen su concesionario. Están ansiosos por recibir comentarios positivos, así que envían la encuesta por correo electrónico sólo a aquellos clientes que hayan comprado dos o más vehículos en el concesionario en los últimos cinco años. ¿Cuál es el resultado probable?

   - [ ] Muestreo aleatorio
   - [ ] Muestreo geográficamente limitado
