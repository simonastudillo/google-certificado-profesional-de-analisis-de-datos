# Procesar datos de sucios a limpios
- Este es el cuarto curso del Certificado en Análisis de datos de Google.
- En este curso, seguirá profundizando en el análisis de datos y en los conceptos y herramientas que utilizan los analistas de datos en su trabajo.
- Aprenderá a comprobar y limpiar sus datos utilizando hojas de cálculo y SQL, así como a verificar e informar sobre los resultados de la limpieza de sus datos.
- Los actuales analistas de datos de Google continuarán instruyéndole y proporcionándole formas prácticas de llevar a cabo las tareas habituales de los analistas de datos con las mejores herramientas y recursos.
- Los alumnos que completen este programa certificado estarán equipados para solicitar puestos de trabajo de nivel introductorio como analistas de datos.
- No es necesaria experiencia previa.
- Al finalizar este curso, los alumnos:
   - Comprobarán la integridad de los datos.
   - Aplicarán técnicas de limpieza de datos utilizando hojas de cálculo.
   - Desarrollar consultas SQL básicas para su uso en bases de datos.
   - Utilizar funciones SQL básicas para limpiar y transformar datos.
   - Verificar los resultados de la limpieza de datos.
   - Redactar un informe eficaz de limpieza de datos

## Módulos

- Módulo 1: La importancia de la integridad
- Módulo 2: Datos limpios para obtener estadísticas más precisas
- Módulo 3: Limpieza de datos con SQL
- Módulo 4: Verificar e informar sobre los resultados de la limpieza
- Módulo 5: Añada datos a su currículum
